Run the page-builder's `build-landing-page` recipe inside the current design-project repo.

1. Read `.claude/commands/_path-remappings.md` for path/output rules and the shared header/footer chrome to use.
2. Read `page-builder/.claude/commands/build-landing-page.md` for the recipe steps. Apply the remappings as you execute.
3. Read `CLAUDE.md` (this repo) for project-specific layout rules and the reference page.
4. After writing the page, run the OVERRIDES harvest step against this repo's `OVERRIDES.md` (not the submodule's).
