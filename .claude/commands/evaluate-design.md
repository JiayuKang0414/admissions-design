description: Evaluate a Page Design
---

Run the page-builder's `evaluate-design` recipe inside the current design-project repo.

1. Read `.claude/commands/_path-remappings.md` for path conventions.
2. Read `page-builder/.claude/commands/evaluate-design.md` for the evaluation steps.
3. The page being evaluated is in this repo's `pages/` folder unless the user specifies otherwise.
