# Interior landing presentation

**Learning that makes a difference** — a visual University of Maryland interior page concept.

View online: https://jiayukang0414.github.io/admissions-design/presentation/interior-landing/

Built with UMD Design System 2.1.0 and page-builder 4cadc21. Includes the default small standard hero, breadcrumb, sidebar, section intro, two-column standard and overlay cards, tabs, accordions, a quote, statistics grid and list, promo banner, curated calendar highlights, curated news, and a YouTube embed.

Content draws on the two supplied Fearlessly Forward reference pages, with source links on the presentation. Calendar highlights are from April 2026; news links point to Maryland Today. All editorial photographs and logos are included in assets/. UMD components, fonts and YouTube require an internet connection.

This directory is standalone and is published by the repository’s existing GitHub Pages workflow.
